# Mood boards

Drop style / content reference images here for **Sakura Studio → Canvas**.

Typical sources: Gemini drafts, Suki boards, pixiv refs. Nested folders are fine
(`gemini/`, `suki/`, `pixiv/`). Studio lists `png` / `jpg` / `webp` / `gif` and
pins them on the Imagine mood-board rail.

These files are **references only**. Canvas generations always write new
`asset.studio.*` catalog assets — originals are never overwritten.

Requires `XAI_API_KEY` (see `.env.example`) for Grok Imagine generate / edit.
